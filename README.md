# Klineto

Статический сайт клининга в Москве и Московской области.

## Как открыть локально

Нужен Python 3. Из корня репозитория:

```bash
python3 server.py
```

Сайт откроется на [http://127.0.0.1:43127](http://127.0.0.1:43127).

Страницы:

- http://127.0.0.1:43127/
- http://127.0.0.1:43127/uborka-kvartir
- http://127.0.0.1:43127/uborka-ofisov
- http://127.0.0.1:43127/privacy
- http://127.0.0.1:43127/cookies

Неизвестный адрес отдаёт страницу 404 со ссылкой на главную.
